# 추상적 조언에서 구체적 선택으로 — 2026-09-17

## 범위와 판정

이번 작업은 디자인이나 기능 추가가 아니라 **행사 글 3개와 서울 비교 가이드 1개의 내용 수정**이다. 실제 외국인 독자 모집이나 운영 배포를 기다리지 않고, 공개된 공식 자료로 답할 수 있는 내용을 직접 조사하고 반영했다. 기존의 다른 작업 파일은 보존했다.

확인된 문제는 ‘직접 확인하라’, ‘비교해 보라’는 조언에 비해 **무엇을 비교하며 그 차이가 선택에 어떤 영향을 주는지**가 부족했다는 것이다. 특히 덕수궁 영어 해설은 공개된 안내가 있는데도 충분히 제공하지 않았다. 이는 이번에 확인한 편집상 결함이며, Google이 개별 페이지의 탈락 원인을 특정해 알려준 증거는 아니다.

성공 조건은 다음과 같이 좁혀 검증했다.

1. 이름 있는 실제 선택지를 제시하고 그 차이를 설명한다.
2. 공식 자료에 있는 언어·입장·시간·장소 조건을 ‘미확인’으로 떠넘기지 않는다.
3. 출처가 말하는 사실과 우리의 비교·추천을 구분한다.
4. 문단에서 근거로 이동할 수 있고, 수정 본문·이미지·기존 링크가 정상 동작한다.

이 조건들은 이번 수정 범위에서 통과했다. 사이트 전체의 콘텐츠 가치나 AdSense 승인 가능성을 점수로 인증한 것은 아니다.

- `data/visitor-briefs.json`, `data/guides.json`, `data/editorial-program.json`: 본문·선택 비교·요약 패널 수정.

## 남은 우선순위

1. 나머지 글의 고유 가치도 같은 수준으로 판단한다. 특히 막연한 관찰 요령이나 공공데이터 목록만으로 충분하다고 보지 않는다. 사진전·드론쇼가 ‘한국 문화 정보’라는 독자 약속에 기여하는지도 계속 검토한다.
2. 외부 독자 검사는 이해하기 어려운 표현·잘못된 추천을 찾는 추가 근거이지, 지금 확인 가능한 본문 결함을 미루는 이유가 아니다. 기존 내부 증빙 항목은 실제 증거 없이 통과로 바꾸지 않았다.
3. 명시적 배포 요청 후 운영 도메인에서 같은 수정본과 현재 사실을 확인한다. 재심사는 별도 결정이다. 이번 작업은 배포·재심사·광고 설정·CMP·커밋·푸시를 수행하지 않았다.

승인에 대한 예상 영향: 단순 재게시와 구분되는 선택·해석의 근거를 늘리고 실제 방문 계획의 오류를 줄이는 방향이다. Google이 이 개선을 충분하다고 판단할지는 확인할 수 없으며, 승인이나 시점을 보장하지 않는다.
