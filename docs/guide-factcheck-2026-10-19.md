# 가이드 24편 팩트체크 (2026-10-20)

대상: `data/guides.json`에서 `keyFacts`가 있는 새 문화 가이드 24편. 기준일은 2026-10-20(KST)이다. 각 가이드의 출처 페이지와 공식 페이지를 다시 받아 읽고 대조했다.

## 요약

- 점검한 사실 주장: **690건**
  - 공식 출처로 확인: 593건
  - 틀림: 39건 / 시효 지남: 13건 → 수정
  - 공식 근거를 찾지 못함: 45건 → 삭제·일반화하거나, 실용 정보가 아닌 해석·관행 서술은 그대로 둠(아래 별도 목록)
- 본문 수정: **120곳**(아래 표 1). 출처 변경: **42건**(아래 표 2).
- 24편 모두 `updatedAt`을 2026-10-20으로 바꾸고, method 문구의 점검일도 "October 20, 2026"으로 바꿨다.
- 출처의 `checkedAt`은 이번에 실제로 다시 읽은 출처와 새로 넣은 출처만 2026-10-20으로 바꿨다. 결과적으로 모든 출처가 오늘 날짜가 됐다.
- 출처가 11개가 된 가이드가 6편이다. 집필 지침의 "출처 4–10개"를 넘지만 검증기 제한은 없다. 무료개방 공지처럼 독자에게 꼭 필요한 근거를 넣기 위해 하나씩 늘렸다.
- 검증 명령: `npm run -s test:editorial`(47/47), `build`, `validate:content`, `validate:original-value` 모두 통과했다. 이것은 구조·추적성 검사이고, 콘텐츠 가치를 판정하지는 않는다.
- 운영 반영: 지금 운영(8a00e21)에는 이 수정이 없다. 작업 트리에만 있고 커밋·배포는 하지 않았다.

### 여러 가이드에 걸친 핵심 발견

1. **2026년 10월 29일~11월 15일 궁능 무료개방(Korea Grand Festival)**
   - 4대궁·종묘·조선왕릉이 무료다. 휴궁일은 제외하고 창덕궁 후원도 제외한다. 종묘는 이 기간 자유관람으로 바뀐다.
   - 4주 안의 일인데 어느 가이드에도 없었다. 궁궐 4편과 한복 가이드에 넣었다.
   - 근거: [궁능유적본부 공지 2026-09-22](https://royal.khs.go.kr/ROYAL/contents/R403000000.do?schM=view&id=20260922161754771774&schBcid=notice01)
2. **창경궁 2026-11-10~15 야간 일반관람 중단**: 「동궐동락」 프로그램 때문에 17:30에 닫는다(입장 16:30까지). 창덕궁·5대궁 가이드에 넣었다.
3. **창덕궁 돈화문 보수**: 2024년 11월부터 공사 중이고 출입은 금호문으로 한다. 기존 문구는 "막혀 있을 수 있음"이었다.
4. **북촌 문화센터**: 영문 페이지가 낡았다. 국문 기준으로 월요일 휴관, 화~금 09–18(수 20시까지), 토·일 09–17이다.
5. **남산골한옥마을**
   - 운영 시간은 운영자 사이트 기준으로 4~11월 21:00이고, 공휴일인 월요일에도 연다. 서울문화포털은 아직 4~10월로 적고 있어 운영자 쪽을 따랐다.
   - 다섯 채 중 옥인동 윤씨 가옥은 이전한 가옥이 아니라 새로 지은 복제 건물이다.
6. **차 문화 가이드**
   - 위키백과 3건을 한국민족문화대백과사전 3건(차, 다방, 의순)과 정책브리핑 1건으로 바꿨다.
   - 백과사전으로 뒷받침되지 않는 서술은 삭제했다: 661년 수로왕 헌다, 1474년 국가 의례 규정, 쌍화차가 다방 최고 인기 메뉴였다는 서술, "참새" 등급 풀이, 초의 "40년".
   - 『다신전』은 초의의 저술이 아니라 중국 문헌을 옮겨 적은 것이라 저작 목록에서 뺐다.
7. **약한 출처 교체**
   - news.nate.com 1건, v.daum.net 2건, 위키백과 5건을 모두 뺐다.
