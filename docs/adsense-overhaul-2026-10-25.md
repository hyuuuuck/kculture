# 애드센스 대비 사이트 전면 정비 (2026-10-25)

## 진단

반려 사유는 "가치가 별로 없는 콘텐츠"다. 10월 20일 이후 가이드 분량은 충분하다. 가이드 33편이 모두 3,000~4,500단어다. 남은 약점은 네 가지로 봤다.

1. **색인 부족**
   - 9/29 Search Console 기준으로 색인 16건, 404 539건이었다. 사이트맵은 예전 12개 URL만 인식했다.
   - 새 가이드는 10/20에 배포했다. 색인 요청은 지금까지 10개 URL만 했다.
   - 심사 크롤러가 새 콘텐츠를 아직 못 봤을 가능성이 크다.
2. **신뢰 페이지와 실제 사이트의 불일치**
   - 편집정책·정정·광고 정책 영어판이 예전 행사·쇼핑 디렉터리 시절 문구 그대로였다. 면세점, 올리브영, K팝 팝업, 제휴 링크 같은 내용이다.
3. **감사 보고서 같은 공개 문구**
   - 행사 페이지에 내부 운영 용어가 노출돼 있었다. 예: "Automated source monitoring", "Retained source evidence; not independently rechecked", "Read the evidence for this article".
   - 홈과 행사 카드에도 비슷한 자기 깎기 문구가 있었다. 예: "not a ranking based on attendance", "2025 reference image, not the 2026 layout".
4. **공식 페이지 요약 이상의 고유 기능 부족**
   - 독자가 직접 쓸 수 있는 도구가 없었다.

## 이번에 바꾼 것 (로컬, 미배포)

- **정책 페이지 재작성(영어)**
  - 편집정책: 독자, 조사 방법, 가이드 구성, 변동 정보와 기간 공지, AI 도구와 책임, 사진, 독립성.
  - 정정: 신고 방법, 확인 방법, 변경 표시 방식, 이미지 삭제 요청.
  - 광고 정책: 광고와 본문의 분리, 유료 게재 불가, 현재 제휴 링크 없음.
  - 이용약관 앞 3개 항목도 지금 사이트에 맞게 고쳤다.
- **정정 페이지에 실제 정정 기록 추가** (`data/corrections-log.json`)
  - 10/20 팩트체크: 690건 점검, 52건 수정.
  - 10/21 기간 공지 이전.
  - 대표 정정 8건을 해당 가이드 링크와 함께 실었다.
- **행사 페이지 템플릿 정리**
  - "Sources and verification limits"를 "Sources"로 바꿨다.
  - 자동 모니터링 날짜, "not independently rechecked" 문구, "Revision scope" 단락을 뺐다.
  - 출처별로 "Checked 날짜"만 남겼다.
- **홈**
  - 앱 기능 위주였던 "Recheck your saved places"를 "Getting around Seoul?"(지하철 가이드)로 바꿨다.
  - "Travelling over a holiday?"를 새 궁궐 운영일 확인기 링크로 바꿨다.
  - 행사 카드의 사진 메모와 순위 부정 문구를 정리했다.
- **새 가이드: Which Seoul Palaces Are Open Today?** (`/en/guides/seoul-palaces-open-today`)
  - 날짜를 고르면 궁 5곳과 종묘의 상태를 보여 주는 확인기다.
    - 운영 여부와 휴궁 사유
    - 계절별 운영시간과 입장 마감
    - 무료 여부(문화가 있는 날, 무료개방 기간)
    - 종묘 시간제·자유관람 구분
  - 규칙은 `palace-days.js` 한 곳에 있다. 빌드(서버 렌더링)와 브라우저가 같은 코드를 쓴다.
  - 데이터는 `data/palace-days.json`이다. 출처는 다음과 같다.
    - 궁능유적본부 관람시간(R702)·관람요금(R703)
    - 서울역사박물관 경희궁 안내
    - 우주항공청 2027 월력요항
    - 10/29~11/15 무료개방 공지와 창경궁 11/10~15 단축 공지
  - 2027년 휴궁 겹침일을 규칙대로 계산해 본문에 실었다.
    - 2/10 수요일, 3/2 화요일, 5/4 화요일에 궁 5곳이 모두 쉰다.
    - 9/17 금요일에 경복궁·종묘가 쉰다.
  - 단위 테스트는 `scripts/tests/palace-days.test.mjs`(3개)에 있다.
- **What's on 허브**
  - 제목과 소개를 바꿨다.
  - 기간 공지를 표시하고, "Every week, all year" 구역을 추가했다. 수문장 교대식 2곳, 토요명품공연, 문화가 있는 날, 종묘 해설, 봉은사 BONG-PASS를 담았다.
  - 분량은 321단어에서 585단어로 늘었다.
- **검증기 갱신**
  - `validate-detail-pages`: 행사 출처 구역을 문구 대신 `id="event-evidence-title"`로 확인한다.
  - `validate-adsense-compliance`: 광고 정책 확인 문구를 새 정책 문장으로 바꿨다. 독립성, 제휴 링크, 연락처 세 가지 취지는 그대로다.

검증: `npm run verify` 통과. 테스트 53/53, 사이트맵 41개 URL이다.

## 재신청 전에 사람이 해야 할 일 (순서대로)

1. **배포**: 이 변경을 main에 반영한다.
2. **Search Console**
   - 사이트맵을 다시 제출한다(41개 URL).
   - 아직 요청하지 않은 가이드 26편과 /en/now/에 색인을 요청한다. 새 확인기 가이드도 포함된다.
   - 하루 약 10건이 한도라 3일쯤 걸린다.
3. **색인 확인**: Search Console 페이지 보고서에서 가이드 대부분이 "색인 생성됨"으로 바뀔 때까지 기다린다. 보통 1~3주다.
4. **운영자 정보**
   - About의 "Who we are"는 지금 "K-Spot Now Editorial Desk"뿐이다.
   - 실명이나 사업자명, 운영 지역 같은 실제 정보를 넣으면 신뢰 신호가 크게 좋아진다.
   - 지어낼 수는 없으니 사용자가 결정해야 한다.
5. **재신청**: 위 단계가 끝난 뒤 재신청한다. 지금 신청하면 크롤러가 새 콘텐츠를 거의 보지 못한 상태에서 심사할 가능성이 크다.

이 정비는 승인을 보장하지 않는다. 기술 검증 통과는 콘텐츠 가치 판정이 아니다.
