# 2026-09-10 개편 구현 기록

범위: 로컬 코드·콘텐츠 수정. 프로덕션 배포, AdSense 재심사, 광고 활성화, 커밋·푸시는 실행하지 않았다.

## 원인 판단과 변경

확인된 Google 반려 사유는 계정 기록의 ‘가치가 별로 없는 콘텐츠’다. 어떤 문장이나 페이지가 반려를 결정했는지 Google이 공개한 것은 아니다. 공식 정보 재서술, 반복적인 확인 항목, 문화 이해·참여 판단의 부족, 날짜 표시 혼동은 운영 사이트와 코드에서 발견한 개선 대상이지 Google 내부 판단을 알아냈다는 뜻은 아니다.

Google은 고유하고 흥미로운 양질의 콘텐츠를 요구한다. 검색 가이드는 단순 재작성 이상의 가치, 명확한 대상과 목적, 실제 변경 없는 날짜 갱신 회피를 권고한다. 검색 가이드와 AdSense 심사 기준은 같은 시스템이 아니다.

- [AdSense 신청 요건](https://support.google.com/adsense/answer/9724?hl=en)
- [Google의 사람 중심 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)

## 기술·운영 수정

- sourceCheckedAt은 자동 출처 모니터링 날짜. Published/Updated, JSON-LD, 사이트맵, RSS 발행일과 분리했다.
- 다른 도시를 ‘근처 대안’으로 연결하지 않으며, 종료된 행사는 현재 관련 링크에서 제외한다.
- 현재 예보가 없으면 그 사실과 KMA 링크를 표시한다. 오래된 관측값을 예보로 채우지 않는다.
- 실제 AI 보조 문헌 조사임을 공개하고 현장 경험이나 가공의 전문가 검토를 주장하지 않는다.
- 글자 수·형식 다양성·점수를 품질 합격의 대용으로 쓰던 핵심 검사를 구조·근거 일치 검사로 바꿨다.
- GSC hold만 보고 ‘보고서가 배포 이전’이라고 단정하던 오류를 실제 날짜 비교로 바꿨다.
- 저장 알림을 닫아도 일정은 유지되며, 작은 화면의 고정 요약은 축소했다.
- preflight:launch는 배포 전 콘텐츠 증빙, preflight:adsense-review는 배포 후 운영 증빙을 요구한다. 배포 전에 배포 완료를 요구하는 순환 조건을 만들지 않았다.

## 검증 상태

### 통과

- npm run verify: 회귀 테스트, 빌드, 콘텐츠·링크·이미지·날짜·달력·구조화 데이터·사이트맵 등.
- 회귀 테스트 9개: 모니터링 날짜 불변성, 실제 수정일 반영, 다른 도시 대안 차단, GSC 날짜 비교, 기사 데이터, 빈 본문/허위 체험 표현, HTML 이스케이프, 증빙 누락·변경 차단, 배포 단계 분리.
- 공식 행사 출처 자동 재확인 6/6 (9월 10일). 키워드 일치는 원문 전체 검토나 실시간 재고 확인과 다르다.
- 로컬 24 HTML의 내부 링크·이미지 참조, 14 URL 사이트맵.
- 인앱 브라우저 1440px 홈·상세 및 390px 홈·가이드·상세의 수평 넘침 없음. 대표 이미지 로딩, 출처 펼치기, 일정 저장, 저장 요약 숨기기 동작 확인.
- Safari에서 로컬 홈 접근·탐색 구조 확인.
- git diff --check.

### 미확인 / 보류

- 실제 외국인 독자의 과제 수행 및 사람이 책임지는 영어·문화 해설 검토. 자동 검사를 이 결과로 대신 기록하지 않았다.
- 새 버전의 운영 배포와 운영 도메인 검증. 기존 계정/GSC 기록은 9월 9일 기록이며 이번에 새 로그인 검사를 했다고 갱신하지 않았다.
- Safari JavaScript 자동 검사는 Apple Events 허용 설정이 꺼져 있어 미확인. 설정을 임의로 바꾸지 않았다. 390px 검사는 인앱 브라우저이며 실제 iPhone Safari 검사가 아니다.
- UI 스킬 검출기의 기존 폰트·장식 관련 경고는 기록상 잔존한다. 이번에는 기존 시각 정체성을 보존하고 독서·탐색을 정리했다.
- Impeccable 업데이트 명령은 기존 설치를 찾지 못해 실패했다. 업데이트 완료로 표시하지 않았다.

### 제출 검사: 의도적으로 차단

data/editorial-release.json의 실제 편집·독자·운영 증빙은 아직 통과가 아니다. 로컬 구현 완료를 AdSense 승인 준비 완료와 같다고 보고하지 않는다.

다음 순서는 개편본의 실제 편집·독자 검토 → 명시적으로 승인된 배포 → 운영 검증 → 현재 계정 조건 확인 → 별도로 승인된 재심사다. 페이지 수를 늘리거나 GSC 숫자를 기다리는 것만으로 대체하지 않는다.
