Official event posters or brand logo thumbnails can be placed here only when the project has permission to use them.

Name each approved file with the event slug, for example:

- `olive-young-uv-care-june-2026.png`
- `bts-world-tour-busan-2026.webp`
- `shilla-duty-free-summer-board-2026.svg`

When `npm.cmd run generate:thumbnails` runs, a matching file in this folder overrides the generated fallback thumbnail for that event.
